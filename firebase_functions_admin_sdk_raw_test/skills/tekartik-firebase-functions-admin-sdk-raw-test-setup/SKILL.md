# Raw emulator test fixture (tekartik_firebase_functions_admin_sdk_raw_test)

A test-only fixture with **no `lib/`**: a minimal firebase project whose single
Cloud Function uses `package:firebase_functions` alone (no tekartik layer), run
end to end in the firebase emulator. It is the reference layout to copy when
adding emulator tests for Dart functions.

## Guidelines

* Package layout, all of it required:
  - `firebase.json` — one `functions` entry with `"source": "functions"`,
    `"codebase": "default"`, `"runtime": "dart3"` and
    `"disallowLegacyRuntimeConfig": true`.
  - `.firebaserc` — `{"projects": {"default": "<project-id>"}}`. The tests read
    the id from it, never hardcode it.
  - `functions/` — its own pub package (`resolution: workspace`) depending on
    `firebase_functions` with `build_runner` in `dev_dependencies`, holding
    `bin/server.dart` and the generated `functions/functions.yaml`.
  - `test/` — the emulator test; `tool/` — the dev menu and the compile script.
  Add the sub package to the repo root `workspace:` list.

* `functions/functions.yaml` is generated by `package:firebase_functions` when
  the emulator (or the deploy) builds the codebase. Never edit it, and delete
  it at the start of a test run so a stale file cannot mask a change (delete
  `File(join('functions', 'functions.yaml'))` before the `group`, see the test
  example below). Regenerate it by hand with
  `firebase emulators:exec --only functions "exit 0"`.

* Because the yaml comes from a static read of `bin/server.dart`, the `name:`
  and every field of the `options:` passed to `onRequest` / `onCall` /
  `onTaskDispatched` / `onMessagePublished` **must be const literals**. A
  computed value produces no endpoint and the test 404s.

* Drive the emulator with `tekartik_firebase_emulator`:
  `FirebaseEmulatorService(path: '.')`, then
  `await service.isSupported()` (false when the firebase CLI, `.firebaserc` or
  the minimum tool versions are missing, or when a running emulator does not
  expose the requested services), `await service.getProjectId()` and
  `await service.start(options: FirebaseEmulatorOptions(onlyFunctions: true, projectId: ..., debug: false))`.
  `start` waits until every emulator is ready (default timeout 180 s). Always
  `await emulator.stop()` in `tearDownAll`.

* Guard the whole file on `isSupported()` and register a single skipped test
  when it is false, so CI without the firebase CLI stays green. Starting the
  emulator and compiling the Dart function is slow: put
  `timeout: const Timeout(Duration(minutes: 5))` on the group and
  `@TestOn('vm')` at the top.

* Function urls in the emulator are
  `http://localhost:5001/<projectId>/<region>/<function-name>`, with the region
  from the function's `options` (`europe-west1` here, `us-central1` when
  unset). Build them with `url.join` from `package:path` and call them with
  `package:http`.

* Add `onlyFirestore`, `onlyAuth`, `onlyPubsub` or `onlyStorage` to
  `FirebaseEmulatorOptions` when the function needs those services; the
  matching `emulators` ports must also be declared in `firebase.json`.
  `persistPath` keeps the emulator data between runs.

* `tool/firebase_functions_raw_menu.dart` just calls `firebaseFunctionsMenuMain`
  from `tekartik_firebase_functions_admin_sdk_test`, an interactive menu to
  delete / generate / dump `functions.yaml` and start / stop the emulator.
  `tool/compile_dart_function.dart` runs
  `dart compile exe bin/server.dart --target-os=linux --target-arch=x64` inside
  `functions/`; `bin/server.exe` is git-ignored.

* This fixture deliberately stays "raw". For functions written against the
  tekartik abstractions and the shared client test suites, use
  `tekartik_firebase_functions_admin_sdk_test` instead.

## Examples

### `functions/bin/server.dart`: the raw function

```dart
import 'package:firebase_functions/firebase_functions.dart';

void main(List<String> args) {
  runFunctions((firebase) async {
    // Async initialization is allowed before registering.
    await Future<void>.delayed(const Duration(seconds: 1));
    firebase.https.onRequest(
      name: 'hello-world',
      // Every option must be a const literal: functions.yaml is generated
      // from this source.
      options: const HttpsOptions(
        cors: Cors(['*']),
        region: Region(SupportedRegion.europeWest1),
        timeoutSeconds: TimeoutSeconds(10),
        maxInstances: Instances(11),
      ),
      (request) async => Response(200, body: 'Hello from Dart Functions!'),
    );
  });
}
```

### `test/emulator_raw_test.dart`: start the emulator and call the function

```dart
@TestOn('vm')
library;

import 'dart:io';

import 'package:http/http.dart';
import 'package:path/path.dart';
import 'package:tekartik_firebase_emulator/firebase_emulator.dart';
import 'package:test/test.dart';

var defaultRegion = 'europe-west1';
var _emulatorService = FirebaseEmulatorService(path: '.');

Future<void> main() async {
  if (!await _emulatorService.isSupported()) {
    test('not_supported', () {}, skip: 'firebase emulator is not supported');
    return;
  }
  // Force re-generation of functions.yaml.
  var file = File(join('functions', 'functions.yaml'));
  if (file.existsSync()) {
    await file.delete();
  }
  final fbProjectId = await _emulatorService.getProjectId();

  group(
    'firebase_functions_dart',
    () {
      late FirebaseEmulator emulator;
      var baseUrl = 'http://localhost:5001/$fbProjectId/$defaultRegion';

      setUpAll(() async {
        emulator = await _emulatorService.start(
          options: FirebaseEmulatorOptions(
            onlyFunctions: true,
            projectId: fbProjectId,
            debug: false,
          ),
        );
      });
      tearDownAll(() async {
        await emulator.stop();
      });

      test('helloWorld', () async {
        var result = await read(Uri.parse(url.join(baseUrl, 'hello-world')));
        expect(result, 'Hello from Dart Functions!');
      });
    },
    // Compiling the dart function and booting the emulator is slow.
    timeout: const Timeout(Duration(minutes: 5)),
  );
}
```

### `tool/compile_dart_function.dart`: build the deployable binary

```dart
import 'package:dev_build/shell.dart';

Future<void> main(List<String> args) async {
  var shell = Shell(workingDirectory: 'functions');
  await shell.run(
    'dart compile exe bin/server.dart --target-os=linux --target-arch=x64',
  );
}
```

### `tool/firebase_functions_raw_menu.dart`: the dev menu

```dart
import 'package:tekartik_firebase_functions_admin_sdk_test/menu/firebase_functions_menu.dart';

/// Menu items: delete / generate / dump functions.yaml,
/// check support, start and stop the firebase emulator.
Future<void> main(List<String> args) async {
  await firebaseFunctionsMenuMain(args);
}
```
